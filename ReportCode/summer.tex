\chapter{Дүгнэлт}

Энэхүү дипломын ажлын хүрээнд annotation болон reflection механизмд суурилсан dependency injection framework-ийг давхаргат архитектурын зарчмын дагуу Java SE 17 орчинд хэрэгжүүллээ. Annotation давхарга, scanner давхарга, container давхарга, injector давхарга болон exception давхарга гэсэн үндсэн бүрэлдэхүүн хэсгүүд нь тус бүр өөрийн үүргийг тодорхой хязгаарын дотор гүйцэтгэж, хоорондын хамаарлыг интерфэйс болон container-оор зохицуулсан. Гуравдагч талын нэмэлт сан ашиглахгүйгээр зөвхөн JDK стандарт сангийн Reflection API болон annotation inspection механизмыг ашигласан нь framework-ийн дотоод ажиллагааг ил тод харуулах судалгааны зорилгод нийцэв.

Хэрэгжүүлэлтийн үр дүнд \texttt{@Component}, \texttt{@Autowired}, \texttt{@Qualifier}, \texttt{@Scope} annotation-уудыг дэмжих, singleton болон prototype scope удирдах, bean-ийг нэр болон төрлөөр авах, dependency injection хийх, тойрог хамаарал илрүүлэх, тодорхой exception шидэх зэрэг системийн шаардлагын бүлэгт тодорхойлсон үндсэн боломжуудыг хангаж чадсан. Энэ нь 2-р бүлгийн шаардлага, 3-р бүлгийн зохиомж, 4-р бүлгийн хэрэгжүүлэлтийн хооронд бодит уялдаа тогтсоныг харуулж байна.

Мөн нэмэлт хэрэгжүүлэлтийн A1 ажлын хүрээнд одоо байгаа хэрэгжилтийн чанарын баталгаажуулалтыг өргөжүүлж, fail-fast exception-уудын мэдээллийн чанарыг сайжруулан, \texttt{unit} болон \texttt{integration} түвшний туршилтын санг цэгцэлсэн. Үүний дараагийн шат болох A3 ажлын хүрээнд dependency tree үүсгэх, DFS ашиглан тойрог хамаарал шинжлэх, dependency tree-г console, JSON болон HTML dashboard хэлбэрээр харагдуулах, мөн \texttt{@EnableIoC} annotation ба \texttt{ApplicationContext.run(Class<?>)} startup загвартай уялдуулсан declarative visualization capability-ийг хэрэгжүүллээ. Ингэснээр framework нь зөвхөн dependency-г шийддэг бус, мөн өөрийн dependency бүтцийг тайлбарлаж, хөгжүүлэгчид ойлгомжтой хэлбэрээр үзүүлдэг болсон.

A3 ажлын үр дүнд container давхаргын дотор dependency graph боловсруулах дэд систем бүрдэж, \texttt{DependencyNode}, \texttt{DependencyTreeBuilder}, \texttt{DependencyTreeExporter}, \texttt{DependencyTreeHtmlExporter} гэсэн шинэ бүрэлдэхүүнүүд бодит хэрэгжилтийн нэг хэсэг боллоо. Энэ өөрчлөлт нь 2-р бүлгийн шаардлагын observability ба testability чиглэлийн уялдааг гүнзгийрүүлж, 3-р бүлгийн layered architecture-ийн хүрээнд container layer-ийн хариуцлагыг dependency analysis болон visualization capability-аар өргөтгөж, 4-р бүлгийн хэрэгжүүлэлтэд dependency graph-ийг startup lifecycle-ийн бодит үр дүн болгон тайлбарлах боломж бүрдүүлсэн. Өөрөөр хэлбэл A3 ажил нь өмнөх бүлгүүдийг тус тусад нь бус, харин харилцан уялдсан нэгдмэл систем болгон бэхжүүлсэн.

Туршилтын баталгаажуулалтын түвшинд A3-ийн дараа framework-ийн тестийн сан мэдэгдэхүйц өргөжиж, dependency tree generation, DFS cycle detection, HTML exporter, startup annotation integration, package auto-detect behavior зэрэг шинэ capability-ууд тусгай integration болон unit тестээр баталгаажсан. Сүүлийн гүйцэтгэлийн баталгаажуулалтаар нийт 66 тест \texttt{0 failures}, \texttt{0 errors} үр дүнтэй амжилттай ажилласан. Иймээс энэхүү framework нь зөвхөн ажиллаж буй туршилтын загвар бус, харин шаардлага, зохиомж, dependency graph observability, туршилтын нотолгоо бүхий илүү боловсорсон судалгааны prototype болсон гэж дүгнэж байна.

Цаашдын өргөтгөлийн хувьд A2 болон A4 ажлуудын хүрээнд constructor injection-ийг илүү бүрэн дэмжих, нэмэлт annotation болон lifecycle hook нэмэх, лог бичих систем, report export, илүү өргөн classpath scanning capability зэрэг боломжуудыг шат дараатайгаар хөгжүүлэх боломжтой хэвээр байна. Гэвч эдгээр дараагийн ажлуудын суурь нь A1-ээр баталгаажсан чанарын хамгаалалт болон A3-аар бий болсон dependency structure-ийг шинжлэх, харагдуулах, тайлбарлах capability байх болно.
